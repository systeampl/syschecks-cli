# syschecks CLI v0.2 — CRUD surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** a registry-driven imperative surface — `list/get/create/update/delete` for all resource types the SDK exposes, `apply -f`, plus incident/agent actions — on top of `syschecks-go` v0.3.3.

**Architecture:** a single **resource registry**. Each type registers one `Resource` value holding closures that adapt its (non-uniform) SDK calls to a common shape returning `map[string]any`. A generic command factory turns a `Resource` into cobra `list/get/create/update/delete` subcommands, wiring hybrid flags+`-f`, output and org resolution. `apply -f` and (later) export/generate iterate the same registry.

**Tech Stack:** Go 1.24, cobra, `syschecks-go` v0.3.3, existing `internal/output`, `internal/clierr`, `internal/config`, `internal/sdkclient`. Tests via the existing `newFakeAPI`/`runCLIOut` harness.

## Global Constraints
- **Go floor 1.24** (SDK requires it). Do not lower.
- **API → SDK → CLI**: never hand-roll HTTP; call `env.SDK.<Namespace>.<Method>`.
- **Exit codes unchanged**: `clierr.Fail`→1, `clierr.Config`→2, success 0. SDK errors → `clierr.Config`.
- **Output unchanged**: `renderTable(env.Out, env.Format, env.Quiet, env.NoColor, output.Table{...})`; `Row = map[string]any`.
- **No flag↔schema drift**: flags for a type are declared once in its `Resource.Fields`; the factory generates cobra flags and the `-f` merge from that single source.
- **Hybrid input**: flags overlay the `-f` document. Nested fields (rotations, steps) are `-f`-only in v0.2.
- **Do not regress v0.1**: existing `org/project/check/notification/incident/agent/probe/verify/auth/config` commands and their tests must keep passing. Types already implemented are refactored onto the registry with the existing tests as the guard.
- **TDD**: every task writes the failing test first (against `newFakeAPI`), then the code.
- **Org resolution**: reuse `resolveOrgID`/`optionalOrgID` (internal/cli/project.go). Types differ in how they take org (path arg / params / none) — the registry entry declares this.

## Interfaces (defined in Task 1, referenced by all)
```go
// internal/cli/registry.go
type OrgMode int
const (
    OrgNone OrgMode = iota // not org-scoped (organizations, status-pages, contact-methods)
    OrgArg                 // org id is a path arg to the SDK call (teams, services, oncall, playbooks, lifecycle, projects, integration-keys)
    OrgParam               // org id rides in a *ListXParams.OrgId (checks, notification-channels, maintenance, incidents)
)

type Field struct {
    Name     string // flag name, kebab (e.g. "url", "interval")
    JSONKey  string // key in the -f document / body (e.g. "url", "interval_seconds")
    Kind     string // "string" | "int" | "bool"
    Required bool   // enforced on create when no -f provides it
    Help     string
}

// A closure set adapting one type's SDK calls. Any nil verb => that subcommand
// is not generated (e.g. agents have no createFn). All return normalized maps.
type Resource struct {
    Name     string   // singular command name, e.g. "team"
    Aliases  []string
    Cols     []string // table columns for list
    Org      OrgMode
    Fields   []Field  // create/update flag set + -f schema

    listFn   func(env *cmdCtx, orgID *int) ([]map[string]any, error)
    getFn    func(env *cmdCtx, orgID *int, id int) (map[string]any, error)
    createFn func(env *cmdCtx, orgID *int, body map[string]any) (map[string]any, error)
    updateFn func(env *cmdCtx, orgID *int, id int, body map[string]any) (map[string]any, error)
    deleteFn func(env *cmdCtx, orgID *int, id int) error
}

// registry is the single source of truth.
var registry = map[string]*Resource{}
func register(r *Resource) { registry[r.Name] = r; for _, a := range r.Aliases { registry[a] = r } }
```

Helpers (Task 1): `toMap(v any) (map[string]any, error)` (marshal a typed SDK response to a map via json round-trip), `bodyFromFlagsAndFile(cmd, fields) (map[string]any, error)` (load `-f` doc if `--file`, overlay flags that were changed), `renderOne`/`renderMany` (map(s) → `output.Table`).

```go
func newResourceCmd(r *Resource) *cobra.Command {
    c := &cobra.Command{Use: r.Name, Aliases: r.Aliases, Short: strings.Title(r.Name) + " resources"}
    if r.listFn != nil { c.AddCommand(newListCmd(r)) }
    if r.getFn != nil { c.AddCommand(newGetCmd(r)) }
    if r.createFn != nil { c.AddCommand(newCreateCmd(r)) }
    if r.updateFn != nil { c.AddCommand(newUpdateCmd(r)) }
    if r.deleteFn != nil { c.AddCommand(newDeleteCmd(r)) }
    return c
}
```
`newListCmd` resolves org per `r.Org` (`OrgParam`/`OrgArg` → `optionalOrgID`; `OrgNone` → nil), calls `r.listFn`, renders `output.Table{Cols: r.Cols, Rows: rows}`. `newGetCmd`/`newDeleteCmd` take `cobra.ExactArgs(1)`, parse int id. `newCreateCmd`/`newUpdateCmd` build the body via `bodyFromFlagsAndFile` and register one cobra flag per `Field` (string/int/bool). `newDeleteCmd` adds `--yes` and prompts on a TTY when absent. Wrap SDK errors as `clierr.Config`.

## Self-review notes
- Every task ends green with the existing harness; Tasks 4-8 are near-identical registry entries differing only by signatures in the Appendix → cheap, mechanical, ideal for fast subagents.
- Body construction uses a generic `mapToBody[T](map) (T, error)` (json marshal map → unmarshal into T) so a type's Create/Update struct is never hand-field-mapped — the SDK model is the schema.
- Irregular verbs (agents, lifecycle, contact-method, integration-key, incidents) are handled by nil verbs / explicit commands, not forced into the generic shape.
